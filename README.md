## About Me

I build full-stack web applications with **React, Next.js, Node.js, Express, and MongoDB**, from authentication and REST APIs to admin dashboards and payment flows. My projects include a learning management system with Redis caching and real-time notifications, and a healthcare appointment platform with separate patient, doctor, and admin panels.

I'm extending my work into **AI engineering**: building LLM-powered applications with LangChain, retrieval-augmented generation (RAG), embeddings, and vector databases.

What I care about most: shipping products people can actually use, clean backend architecture and API design, and learning how to deploy and scale what I build.

---

## AI Engineering & Current Exploration

**Built hands-on**
- Python for AI applications
- LangChain & LCEL (LangChain Expression Language) pipelines
- RAG: document ingestion, text splitting, embeddings, retrieval, and context-based generation
- ChromaDB as a vector store for semantic search
- LLM integrations with Groq and Gemini APIs
- Streamlit interfaces for custom-document Q&A apps

**Actively learning**
- AI agents and tool-calling workflows
- LangGraph for agent orchestration
- Evaluation and production deployment of LLM apps
